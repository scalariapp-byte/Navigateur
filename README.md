# Fanfic Hub

Lecteur Android de fanfictions, au design sombre et soigné.

- **AO3** : connexion au compte, favoris, liste « à lire », abonnements, détection des nouveaux chapitres.
- **Lecteur** : plein écran, 3 thèmes (Nuit, Sépia, Papier), taille du texte, sommaire, lecture hors ligne, reprise exacte.
- **Spirit Fanfics, Wattpad, FanFiction.net** : bibliothèque du compte, ou ajout par lien / partage depuis Chrome.
- **Mises à jour** intégrées (onglet Compte ou bannière sur l’accueil).

APK : https://github.com/scalariapp-byte/Navigateur/releases/download/fanfichub/FanficHub.apk
